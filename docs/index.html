SECTION // 01 Operational Overview

HP-MOD-OVERVIEW

Autonomous coding agents produce code quickly, but without rigorous controls they accumulate hidden regressions, hallucinated test passes, and unreviewed architectural drift. HowlPlane establishes a deterministic operational control plane that wraps multi-agent work in verifiable safety boundaries.

Operational Dimension Unstructured Agent Interaction HowlPlane Control Plane Verification Anchor
Task Assignment Ad-hoc prompt guessing Deterministic capability & tier matching ROUTER
Code Review Cheerleading diffs Adversarial falsification briefs FALSIFICATION
Claim Validation Trusting agent text output Subprocess test suites & slopslint gates VERIFIED
Consequential Actions Unbounded agent mutations Fail-closed human sign-off gates HUMAN AUTH

SECTION // 03 Everyday Developer Workflow

HP-MOD-CLI

Developers interact directly with the control plane from inside any active project repository via the unified ai CLI command:

[BASH // OPERATOR_COMMANDS] 
# 1. Stand inside any repository and work an objective:
cd /path/to/project
ai work "fix the highest-value open bug"

# 2. Inspect active context, verification suites, and task runs:
ai status

# 3. Deterministically route a task and pick reviewer roles without mutating code:
ai route "patch authentication vulnerability"

# 4. Run system preflight diagnostics and environment doctor checks:
ai doctor

# 5. Execute deterministic verification suites on the active repository:
ai verify

# 6. Check human approval boundary status and pending sign-offs:
ai approve --list

SECTION // 04 Core Capabilities & Subsystems

HP-MOD-SUBSYSTEMS
  • Deterministic Task Routing (src/control_plane/router.py): Matches task risk tiers and reasoning demands to agent profiles without remote LLM calls.
  • Specialized Independent Reviewers (src/control_plane/reviewers.py): Generates targeted falsification briefs designed to catch contract breaks, injection vectors, and missing test branches rather than cheerleading diffs.
  • Review Reconciliation (src/control_plane/reconciler.py): Synthesizes findings into confirmed, likely, disputed, or requires_human status. Silent dismissal of blocker/high findings is strictly forbidden.
  • Deterministic Verification Suites (src/control_plane/verification.py): Subprocess-based build, test, lint, and repository hygiene gates (slopslint) enforcing monotonic quality ceilings.
  • Durable Evidence Ledger (logs/control_plane/evidence_ledger.jsonl): Append-only JSONL record of task transitions, reviewer findings, and verification outcomes with automated credential sanitization.
  • Human Authority Boundaries (src/control_plane/human_boundary.py): Fail-closed boundary gate requiring explicit human sign-off on deployments, destructive migrations, secret rotation, package publishing, and policy weakenings.

SECTION // 06 HowlFrame Relationship

HP-MOD-HOWLFRAME

HowlPlane serves as a primary real-world dogfooding consumer of the HowlFrame language and capability-bounded execution runtime:

[SCHEMATIC // ECOSYSTEM_RELATIONSHIP] STACK_TIERS 
HowlPlane (AI Engineering Control Plane)
      │
      ├── Normal deterministic tooling (Go, Python, Make, Git)
      │
      ├── AI coding agents (Claude Code, Codex, Gemini CLI, Devin CLI, Antigravity)
      │
      └── HowlFrame bounded execution runtime (policy execution & verification paths)
  • Why HowlPlane dogfoods HowlFrame: Smaller applications prove individual language constructs; ChangeOps proves governed release mutation; HowlPlane provides high-frequency engineering workloads that pressure generated structured programs, capability boundaries, instruction budgets, and result normalization.
  • Independence: HowlPlane remains completely usable without HowlFrame. HowlFrame is an optional runtime dependency for selected bounded operations.

SECTION // 08 Quick Start & Installation

HP-MOD-INSTALL

1. Standalone Binary Installer (Recommended)

Download the latest ai_installer binary from GitHub Releases and run:

[TERMINAL // INSTALLER] 
./ai_installer

2. Repository Setup

[TERMINAL // SETUP] 
git clone https://github.com/howlcipher/howlplane.git
cd howlplane

# Run global installer (links rules to Claude, Codex, Gemini/Antigravity, Devin):
chmod +x scripts/install_global.sh
./scripts/install_global.sh

# Or install Python development environment:
pip install -e ".[dev]"

3. Control Plane Discovery Precedence

  1. --control-plane-dir <path> CLI flag
  2. HOWLPLANE_HOME or HOWLPLANE_DIR environment variable
  3. AI_KNOWLEDGE_LIBRARY environment variable (deprecated fallback)
  4. ~/.config/howlplane/config.toml (canonical) → ~/.config/ai-control-plane/config.toml (legacy)
  5. Self repository root detection
